# Interview Pilot — 구조화 AI 면접 코치

카메라와 마이크를 이용해 실제 면접 흐름으로 연습하고, **질문별 평가기준·답변 근거·STAR/PREP 구조·말하기·화상 전달**을 함께 분석하는 React/Vite 웹앱입니다.

## 현재 구조

### 1. 구조화 면접

- 직무·회사·경력·채용공고·집중 평가 역량을 기반으로 질문을 생성합니다.
- 각 질문에는 `questionType`, `competency`, `framework`, `targetSeconds`, `rubric`이 함께 생성됩니다.
- BEI 역량면접에서는 일반적인 답변보다 **사용자가 실제로 한 행동(Action), 판단 근거, 결과(Result)**를 우선 검증합니다.
- 답변이 모호하면 이전 답변의 빈틈을 파고드는 후속 질문을 생성합니다.

### 2. 두 가지 연습 모드

- **코칭 모드**: 질문별 평가 포인트를 확인하고, 답변 후 점수·평가기준별 근거·구조 누락·개선답변을 충분히 본 다음 직접 다음 질문으로 진행합니다.
- **실전 모드**: 중간 점수와 코칭을 숨기고 질문을 연속 진행한 뒤 최종 리포트에서 한 번에 복기합니다.

### 3. 답변 분석

답변마다 다음을 평가합니다.

- 질문 관련성: 질문의 실제 의도에 직접 답했는지
- 답변 구조: STAR / PREP / CAR 등 질문에 맞는 구조
- 근거 밀도: 구체적인 행동·수치·결과·판단 근거
- 전달력: 실제 말속도·침묵·군더더기 표현 및 표현 명료도
- 직무 연결: 해당 경험을 지원 직무의 요구역량과 연결한 정도
- 질문별 rubric: 평가기준마다 점수, 답변 속 근거, 다음 답변에서의 행동 제시
- 역량 평가: 답변 속 관찰 가능한 행동지표를 근거로 핵심 역량 평가

현재 질문 텍스트와 질문별 rubric을 서버에 함께 보내기 때문에 답변만 따로 떼어 일반적으로 평가하지 않습니다.

### 4. 화상·음성 분석

- **기기 내 실시간 분석**: MediaPipe와 Web Audio API로 프레이밍, 카메라 방향 시선 근사치, 움직임 안정성, 음성 에너지를 계산합니다.
- **AI 화상 코칭**: 사용자가 켠 경우 답변이 실제로 시작된 뒤 최대 10초의 저용량 무음 영상과 최대 4장의 프레임을 Gemini에 전달합니다.
- 질문 낭독 시간과 답변 전 생각하는 시간은 답변 말속도·침묵 측정 및 AI 영상 표본에서 제외합니다.
- 사용자는 면접 중 자신의 화면을 숨길 수 있으며 분석은 계속됩니다.
- 외모, 성별, 나이, 인종, 장애, 건강상태, 성격, 감정을 추론하거나 평가하지 않습니다.

### 5. 반복 연습과 리포트

완료한 세션은 브라우저 `localStorage`에 최대 20개 저장합니다.

최종 리포트에는 다음을 표시합니다.

- 면접 준비도와 종합점수
- 같은 목표 직무의 이전 연습 대비 점수 변화
- 질문 관련성 / 구조 / 근거 / 전달 / 직무연결 scorecard
- 역량 매트릭스와 답변 근거
- 실제 말속도 / 군더더기 표현 / 침묵 / 시선 지표
- 우선 개선과제
- 반복 가능한 practice queue와 성공 기준
- 7일 훈련 계획
- 문항별 질문·답변·평가기준·구조분석·개선답변 복기

외부 사용자 모집단 데이터가 없으므로 근거 없는 백분위·타 지원자 순위는 표시하지 않습니다. 현재는 사용자의 과거 세션과 비교합니다.

## AI 모델

기본 우선순위는 다음과 같습니다.

1. `GEMINI_API_KEY`가 있으면 `gemini-3.1-flash-lite`
2. Gemini가 없거나 `AI_PROVIDER=openai`이면 `gpt-4o-mini`
3. `AI_PROVIDER=auto`에서 Gemini 호출이 실패하고 OpenAI 키가 있으면 OpenAI로 자동 대체

기존 배포 환경에 `GEMINI_MODEL=gemini-2.5-flash-lite`가 남아 있어도 서버가 자동으로 `gemini-3.1-flash-lite`로 치환합니다. Gemini는 영상 입력을 직접 처리하고 OpenAI 대체 경로는 프레임만 사용합니다.

```text
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.1-flash-lite
AI_PROVIDER=auto

# 선택적 대체 경로
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4o-mini
```

## AI 면접관 턴테이킹

`src/InterviewTurnManager.jsx`가 브라우저 TTS와 자동 턴을 담당합니다.

1. 새 질문을 감지합니다.
2. 질문을 음성으로 읽는 동안 사용자 음성 인식을 끕니다.
3. 질문 낭독이 끝나면 자동으로 음성 인식을 시작합니다.
4. 이 시점부터 답변 타이머·말하기 지표·영상 표본을 수집합니다.
5. 답변이 20자 이상이고 답변 시작 후 7초가 지난 뒤 약 4.5초간 전사 변화가 없으면 자동 제출합니다.

면접 화면의 보조 패널에서 질문 음성, 자동 턴, 질문 다시 듣기를 제어할 수 있습니다.

## 호출 경로

1. `src/App.jsx` `beginInterview()` → 구조화 첫 질문과 질문 rubric 생성
2. `src/InterviewTurnManager.jsx` → 질문 낭독 및 마이크 handoff
3. `src/App.jsx` `startListening()` → 답변 시점부터 텔레메트리·영상 표본 수집 시작
4. `src/App.jsx` `submitAnswer()` → 현재 질문, 질문 meta, 답변, 텔레메트리, 영상 표본 전달
5. `src/services/chatgptService.js` → `/api/chat`
6. `api/chat.js` / `server/index.js` → `server/coach.js`
7. `server/coach.js` → Gemini 우선 구조화 평가 및 후속 질문
8. 마지막 질문 → 최종 준비도·역량·전달 지표·연습 계획 생성

## 실행 및 빌드

```bash
npm install
npm run dev
npm run build
```

카메라와 마이크는 HTTPS 보안 컨텍스트가 필요합니다. Chrome 또는 Edge를 권장합니다.

## 실사용 테스트

1. 우선 `3문항 · 빠른 점검`과 `코칭 모드`로 시작합니다.
2. 질문 음성이 끝난 뒤 마이크가 자동으로 켜지는지 확인합니다.
3. 질문을 듣는 동안 타이머가 사실상 답변 시간으로 누적되지 않는지 확인합니다.
4. 답변 후 자동 제출되면 피드백이 바로 사라지지 않고 화면에 유지되는지 확인합니다.
5. 관련성·구조·근거·전달·직무연결 점수와 rubric별 근거가 나오는지 확인합니다.
6. STAR/PREP 단계별 충족/부분/누락이 표시되는지 확인합니다.
7. `피드백 확인 완료 · 다음 질문`을 눌렀을 때 이전 답변의 빈틈과 연결된 후속 질문이 나오는지 확인합니다.
8. AI 모델이 `gemini / gemini-3.1-flash-lite`로 표시되는지 확인합니다.
9. 3문항 완료 후 준비도·역량 매트릭스·말하기 지표·practice queue가 포함된 최종 리포트가 표시되는지 확인합니다.
10. 같은 직무로 두 번째 세션을 완료해 이전 연습 대비 점수 변화가 표시되는지 확인합니다.
